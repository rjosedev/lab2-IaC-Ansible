
# Device - RTB-PE2

## Configuraciones de interfaces P-PE

### hostname: RTB-PE2

```
!
interface Loopback0
  description ### Loopback0 for BGP Router ID ###
  ip address 10.0.0.14 255.255.255.255
  no shutdown
  ip router isis CORE
!
interface GigabitEthernet0/0
  description ### Link to RTM-P5 ###
  ip address 10.0.62.2 255.255.255.248
  no shutdown
  ip router isis CORE
  mpls ip
!
interface GigabitEthernet0/1
  description ### Link to SWB-CE2 ###
  ip address 10.2.2.6 255.255.255.248
  no shutdown
  ip vrf forwarding VRFgreen
!
```
