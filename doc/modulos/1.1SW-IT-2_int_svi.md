
# Device - SW-IT-2

## Configuraciones de interfaces SVI

### hostname: SW-IT-2

```
!
interface vlan 70
  description ### SVI interface for VLAN70_IT1 ###
  no shutdown
  ip address 10.0.700.251 255.255.255.0
  vrrp 70 ip 10.0.700.254
  vrrp 70 priority 2
!
interface vlan 80
  description ### SVI interface for VLAN80_IT2 ###
  no shutdown
  ip address 10.0.800.251 255.255.255.0
  vrrp 80 ip 10.0.800.254
  vrrp 80 priority 1
!
```
