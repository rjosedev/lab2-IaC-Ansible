
# Device - RTA-P5

## Configuraciones de BGP

### hostname: RTA-P5

```
!
router bgp 65111
bgp log-neighbor-changes
neighbor MPLS peer-group
neighbor MPLS remote-as 65111
neighbor MPLS update-source Loopback0
neighbor 10.0.0.32 peer-group MPLS

address-family ipv4
no synchronization
neighbor MPLS send-community both
neighbor MPLS soft-reconfiguration inbound
no neighbor 10.0.0.32 activate
no auto-summary
exit-address-family

address-family vpnv4
neighbor MPLS send-community both
neighbor 10.0.0.32 activate
exit-address-family
!
```
