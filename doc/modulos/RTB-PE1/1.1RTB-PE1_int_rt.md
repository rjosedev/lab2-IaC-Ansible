
# Device - RTB-PE1

## Configuraciones de interfaces P-PE

### hostname: RTB-PE1

```
!
interface Loopback0
  description ### Loopback0 for BGP Router ID ###
  ip address 10.0.0.13 255.255.255.255
  no shutdown
  ip router isis CORE
!
interface GigabitEthernet0/0
  description ### Link to RTM-P5 ###
  ip address 10.0.51.1 255.255.255.248
  no shutdown
  ip router isis CORE
  mpls ip
!
interface GigabitEthernet0/1
  description ### Link to SWB-CE1 ###
  ip address 10.2.1.6 255.255.255.248
  no shutdown
  ip vrf forwarding VRFgreen
!
interface GigabitEthernet0/2
  description ### Link to SWD-CE1 ###
  ip address 10.4.1.6 255.255.255.248
  no shutdown
!
```
