
# Device - RTA-PE1

## Configuraciones de interfaces P-PE

### hostname: RTA-PE1

```
!
interface Loopback0
  description ### Loopback0 for BGP Router ID ###
  ip address 10.0.0.11 255.255.255.255
  no shutdown
  ip router isis CORE
!
interface GigabitEthernet0/0
  description ### Link to RTM-P3 ###
  ip address 10.0.13.1 255.255.255.248
  no shutdown
  ip router isis CORE
  mpls ip
!
interface GigabitEthernet0/1
  description ### Link to SWA-CE1 ###
  ip address 10.1.1.6 255.255.255.248
  no shutdown
  ip vrf forwarding VRFgreen
!
interface GigabitEthernet0/2
  description ### Link to SWC-CE1 ###
  ip address 10.3.1.6 255.255.255.248
  no shutdown
!
```
